# Strange Sightings & UFO Category

## Goal
Add a 17th browse category named **Strange Sightings & UFO** to Home and Community, using the supplied neon UFO artwork and clear ways to report, browse, or request mystery footage.

## Changes
- Upload the supplied UFO image to the app asset store and use it as the category artwork, centered and cropped consistently on every card.
- Add the new card to the Home explore drawer with a cyan/lime neon treatment that matches Onlooker's dark visual system.
- Add a focused Home panel for this category that filters map bounties and recorded/live items using mystery and sighting terms.
- Add the 17th card to Community's **Explore by vibe** grid with relevant filters such as UFO, unexplained lights, unusual aircraft, strange sounds, and unexplained events.
- Add a compact action panel with **Report Sighting**, **View Community Logs**, and **Request a Mystery Bounty**.
- Connect reporting and logs to the Community experience, and connect mystery bounty requests to the existing POST landing page.

## Guardrails
- Keep the broadcast, Flash, and stream-creation category pickers unchanged; this is a browse/home category only.
- Reuse existing live and recorded feeds rather than creating sample media.
- Keep the shared clean light map style unchanged.

## Verification
- Confirm the custom image displays rather than an emoji on Home and Community.
- Confirm all three actions navigate or filter correctly.
- Confirm mystery results appear consistently in feed and map views, with a useful empty state when none exist.
- Run the project type check and verify Home and Community at phone and desktop sizes.
